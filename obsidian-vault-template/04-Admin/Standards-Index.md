## How to Update a Standard

1. Edit the relevant file in `02-Standards/`
2. Go to the Build Planner → Admin → Standards
3. Delete the old version and re-upload (or paste the updated text)
4. Mark it Active
5. Update the "Last Updated" date in the table above

## How to Add a New Standard

1. Create a new `.md` file in the appropriate `02-Standards/` subfolder
2. Go to Build Planner → Admin → Standards → Upload Document
3. Select the category and mark as Active
4. Add a row to the table above
