# Template: New Client Project Checklist

Use this checklist every time you start a new client engagement.

## Week 1 — Kickoff

- [ ] Create client folder in `01-Clients/[ClientName]/`
- [ ] Copy all files from `01-Clients/_template/` into the new folder
- [ ] Fill in `00-Client-Overview.md`
- [ ] Fill in `01-Pre-Sales.md` from AE handoff notes
- [ ] Create project in **Zennify Build Planner** tool
- [ ] Schedule discovery sessions

## Week 1–2 — Discovery

- [ ] Complete Digital Maturity Assessment with client
  - [ ] Enter scores into `02-Maturity-Assessment.md`
  - [ ] Enter scores into Build Planner tool (Maturity Assessment form)
- [ ] Run discovery sessions, capture notes in `03-Discovery/`
- [ ] Collect tech stack information
- [ ] Obtain / upload SOW PDF to Build Planner

## Week 2–3 — Planning

- [ ] Upload all discovery docs to Build Planner
- [ ] Run AI analysis in Build Planner
- [ ] Review AI-generated outcomes, epics, stories
- [ ] Copy plan summary to `04-Project-Plan.md`
- [ ] Generate client shareable link from Build Planner
- [ ] Send client shareable link for review
- [ ] Client sign-off on plan

## Week 3 — Jira Setup

- [ ] Export epics/stories from Build Planner as CSV
- [ ] Import CSV into Jira
- [ ] Set up sprints
- [ ] Sprint 1 planning meeting

## Ongoing

- [ ] Log all meetings in `05-Meeting-Notes/`
- [ ] Update project plan as scope changes
