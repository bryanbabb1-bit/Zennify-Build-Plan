# Standard: Zennify Delivery Process

**Category:** Delivery Process
**Status:** Active

---

## Engagement Phases

### Phase 1 — Discovery & Planning
- Digital Maturity Assessment
- Stakeholder interviews
- Current state documentation
- AI-generated project plan (outcomes → epics → stories)
- Client plan review & sign-off

### Phase 2 — Design
- Solution design document
- Data model review
- Integration architecture
- Security model design
- Client design review & sign-off

### Phase 3 — Build (Sprints)
- 2-week sprints
- Sprint planning from Jira backlog
- Daily standups
- Sprint demo + client review
- Regression testing each sprint

### Phase 4 — UAT
- Client performs UAT against acceptance criteria
- Defect triage and resolution
- Sign-off document

### Phase 5 — Go-Live & Hypercare
- Deployment runbook
- Data migration (if applicable)
- Training sessions
- 30-day hypercare support window

---

## Definition of Done

A story is done when:
1. Built and unit tested in Dev sandbox
2. Deployed to QA and integration tested
3. Client UAT passed
4. Code reviewed by senior consultant
5. Deployed to Production via change set or CI/CD pipeline

## Sprint Ceremonies

| Ceremony | Cadence | Duration |
|---|---|---|
| Sprint Planning | Start of sprint | 2 hours |
| Daily Standup | Daily | 15 min |
| Sprint Review/Demo | End of sprint | 1 hour |
| Retrospective | End of sprint | 30 min |
